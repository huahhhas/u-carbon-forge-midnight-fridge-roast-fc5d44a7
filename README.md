# Midnight Fridge Roast

One line: a roast of a smart fridge that refuses to open after midnight.

## Entry

> My fridge hired a bouncer at midnight — apparently the leftovers filed a restraining order against me.

The fridge does not merely lock itself; it hires a bouncer, and the leftovers have taken out a restraining order against their own owner.

## Run

```sh
python3 main.py
```

Prints the entry line to stdout and writes it to `/output/entry.txt`.
